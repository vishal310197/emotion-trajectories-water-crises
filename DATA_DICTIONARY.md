# Data Dictionary

## Project

**Emotion Trajectories in Online Discourse During Drinking Water Contamination Crises: A Comparative Social-Sensing Study**

This document describes the processed files recommended for the public
reproducibility package. The analysis uses seven emotion classes:

- `anger`
- `disgust`
- `fear`
- `joy`
- `neutral`
- `sadness`
- `surprise`

`neutral` is an emotion-classifier category used in the descriptive analysis.
Its inclusion with `joy` in the EmoEle calculation does **not** imply positive
affect, trust, optimism, satisfaction, or social cohesion.

## 1. `reference_development.csv`

### Purpose

This is the expert-reviewed model-development pool used for standard
fine-tuning and the reported LoRA experiment.

### Record count

**5,836 records**

The notebook divides this pool internally into:

- 4,668 records for internal training (80%)
- 1,168 records for internal validation (20%)

### Fields required by the reported training code

| Field | Meaning | Used in model fitting? |
|---|---|---|
| `body` | Text supplied to the DistilRoBERTa tokenizer | Yes |
| `predicted_emotion` | Expert-reviewed reference emotion label | Yes |

The historical working file contains many additional fields inherited from
earlier processing stages. They are not all required to reproduce the
classifier.

### Public-release recommendation

Remove columns whose names begin with `Unnamed:` and remove unnecessary
personal/platform-identifying fields such as `author` and direct user-level
URLs unless their redistribution is necessary and permitted.

## Derived temporal variables

The temporal-analysis notebook derives case-specific temporal bins:

| Case | Aggregation |
|---|---|
| Nokia | Weekly |
| Flint | Yearly |
| Iqaluit | Monthly |

Within each temporal bin, emotion counts are converted to proportions.

### EmoEle

The descriptive Emotional Elevation summary is calculated as:

`(joy + neutral) - (anger + fear + disgust + sadness + surprise)`

The resulting case-specific series is min-max normalized to `[0, 1]`, then
smoothed using a centered three-bin rolling mean. Boundary values generated
by the centered rolling window are completed using backward and forward
filling.

EmoEle is a descriptive composite of observed online discourse. It is not a
validated measure of population trust, compliance, psychological state, or
governance quality.

## Keyword extraction

The manuscript reports **YAKE** keyword extraction. Keywords are used only
as qualitative lexical context and not as classifier validation.

Legacy KeyBERT cells present in exploratory notebooks are not part of the
reported manuscript workflow and should be removed or clearly marked as
exploratory in the public repository.
